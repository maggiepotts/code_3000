# Security Policy

This document outlines my intended audience, my security risk threats, and the steps I have taken to secure this repository.

## 1. Intended Users & Scope

The code and data contained within this repository are explicitly developed for and restricted to:
* **Maggie Potts:** For personal reference, portfolio building, and tracking coursework progress.
* **Matt Lamoureux and TAs:** For grading, feedback, and academic evaluation.

## 2. Security Threat & Risk Assessment

I analyzed the potential impact if the code or data in this repository fell into the wrong hands or was maliciously modified.

* **Academic Misconduct:** If another student copies this code for their own homework, it could lead to plagiarism and violations of the university's academic integrity policy.
* **Academic Sabotage:** If an outside user gain access, it could lead to code manipulation/deletion resulting in me having to do more work.

## 3. Repository Protection Measures

To mitigate the threats outlined in our risk assessment, the following repository safeguards are implemented:

* **Code Owners Enforced (`CODEOWNERS`):** A `CODEOWNERS` file is set up with the **Professor Lamoureux** designated as the sole reviewer for code changes.
* **`.gitignore` Configuration:** A `.gitignore` file blocks local environment files and system clutter from being uploaded to the cloud.
